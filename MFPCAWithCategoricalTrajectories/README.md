# MFPCA for Temporal Categorical Data

This repository contains **R scripts and functions** for performing **Multivariate Functional Principal Component Analysis (MFPCA)** on temporal categorical data.

The aim is to provide tools for applying MFPCA to temporal categorical data and exploring their main sources of variability within a functional framework.

The repository is organized into two main parts:

- The **`MFPCA_Cardot_2026`** directory contains the scripts used to reproduce the analyses and results presented in **Cardot and Peltier (2026)**.
- The **`Functions`** directory contains the R functions developed and used for the MFPCA methodology presented in **Peltier and Cardot (2027, Food Quality and Preference)**, that can be reproduced using analysisGusot_TCATA_MFPCA8FQP_260707.r.
